# Beca Flow

Beca Flow, modern, şeffaf ve minimalist bir müzik stüdyosu platformudur. Kullanıcıların müzik dinleme deneyimini sosyal paylaşım ve kayıt özellikleri ile birleştiren, açık kaynaklı bir web uygulamasıdır.

## 🚀 Özellikler

- **Müzik Çalar:** Sürükle-bırak desteği ile ses dosyalarını oynatma.
- **Şarkı Sözü Senkronizasyonu:** Dinlediğin parçaların sözlerini gerçek zamanlı takip etme.
- **Kayıt Stüdyosu:** Dahili mikrofon özelliği ile ses kaydı alma.
- **Sosyal Paylaşım:** Dinlediğin parçaları tek tıkla Bluesky üzerinden paylaşma.
- **Kütüphane Yönetimi:** Yüklenen dosyaları düzenli bir şekilde listeleme.
- **Minimalist Tasarım:** Modern arayüz ve şeffaf katmanlar (Glassmorphism).

## 🛠️ Nasıl Çalışır?

Beca Flow, herhangi bir sunucu kurulumu gerektirmeyen, doğrudan tarayıcı üzerinden çalışan bir web uygulamasıdır. `index.html` dosyasını tarayıcınızda açmanız yeterlidir.

# Beca Flow

Beca Flow is a modern, transparent, and minimalist music studio platform. It is an open-source web application designed to merge your music listening experience with social sharing and real-time recording features.

## 🚀 Features

- **Music Player:** Smooth audio playback with drag-and-drop file support.
- **Synced Lyrics:** Real-time lyric synchronization for an immersive experience.
- **Recording Studio:** Built-in microphone support for capturing your voice.
- **Social Sharing:** Share your current track directly to Bluesky with a single click.
- **Library Management:** Easily organize and access your uploaded audio files.
- **Minimalist Design:** Sleek interface featuring modern glassmorphism aesthetics.

## 🛠️ How it Works

Beca Flow is a client-side web application that runs directly in your browser without any server setup required. Simply open the `index.html` file in any modern web browser to get started.
